Keyboardia · design spec · replaces LoopRuler (31G)

Loop Pages & Capture

The LoopRuler failed because it was a proxy pretending to be a header: a proportional strip that couldn't align with a per-track-scrolling grid, drag-only gestures that fought touch scrolling, and loop semantics defined in the one coordinate space users never see. This redesign keeps the synced loopRegion engine and replaces the control surface with page chips (the product's existing 16-step unit) plus handles on the mini-map — and pays the feature off with Capture, the bridge from loops to patterns.

Lesson 1 · geometry

Two honest surfaces, zero proxies. Semantic chips need no alignment; the mini-map is honestly proportional because it shows real content. Nothing pretends to line up with cells.

Lesson 2 · semantics

Loop in pages, not raw steps. Bars of 16 global steps — the unit the grid already draws as separators. One shared definition drives scheduler, dimming, and display.

Lesson 3 · honesty

Never dim a sounding step. Short tracks show a cycle count (↻2) instead of the old false dimming. What glows is what plays.

Lesson 4 · input

Taps first, drags as refinement. Chips are buttons: touch, keyboard, and screen-reader native. Fine drag handles exist only where a pointer does.

1Page chips are the loop control. Click 2 = loop page 2. Click 3 = extend to 2–3. Click an active chip = release it; clicking the only active chip clears the loop. Every state is visible — no pending modes, no double-click, no Shift grammar.
2Mini-map = the honest overview. Rows are real track content, so proportional geometry is legible. The loop region gets true drag handles ⟨ ⟩ for sub-page trims (pointer only, snaps to beats). Playhead sweeps the looped span.
3Capture appears only while a loop is active. One click prints what you're hearing — every track's audible slice, polyrhythm interference included — as a new pattern.
4Pattern chips show where Capture lands and where song mode grows. Playing pattern carries the orange dot.
5Cycle badges replace false dimming. Kick (16 steps) plays twice per loop → ↻2, fully lit. Only the 64-step Lead — where page geometry is real — dims its out-of-loop pages.

Engine unchanged: loopRegion {start,end} stays synced through the Durable Object and both schedulers. The redesign constrains authoring to page boundaries (handles snap to beats), derives all UI from one shared loopMembership() helper — replacing the dead, contradictory isStepInLoop() — and adds capture_loop as a standard synced mutation. Multiplayer: chips flash the acting player's color, like every other attributed change.
