Category Color: eight options, one principle

The strip's jobs are scanning (find the drums without reading), sectioning (same-hue neighbors read as a block), and anchoring (row identity survives horizontal scroll) — all classification, never state. Every option below is drawn on the same three rows, including a soloed row (purple outline) and a muted row (yellow M, dimmed) — because the real test is whether classification stays legible and quiet next to state.

Recommendation: the name label (O6)

Edges signal state. Labels signal class.

The row's border/outline belongs exclusively to state — mute, solo, selection, playing, drag-target — and classification moves into the one element whose job is already identity: the track name. This is the label/tag idiom every user knows from GitHub, Airtable, and Linear, applied with Keyboardia's own category hues (unchanged from the SamplePicker, so the choose→find loop still closes).

  • Spec: name chip background color-mix(category 14%, surface), border 1px color-mix(category 42%, transparent), radius 4px, text stays --color-text. Dims with the row when muted. Non-interactive surface is unchanged (name keeps its click-preview / rename behaviors).
  • Consistency (Repetition): the same label treatment carries category in the MixerPanel channel headers and the SamplePicker rows — one rule everywhere color classifies.
  • Hue at area, not width: ~44×20px of 14% tint + a 42% border reads its hue reliably where 1px of 100% could not — small-area color needs area, not just saturation.
  • Vocabulary cost: zero. No new affordance, no new column — it's the existing status-pill/badge frame (contact sheet K19) applied to an existing element. The border-left disappears entirely.
  • If sectioning ever needs reinforcement (many same-category adjacent tracks), the O4 wash at ≤6% can be layered later as a group treatment — a separate decision, gated like everything else.
  • On the grip variants (O7/O8): their real merits — zero template cost, a clean name, double-duty for the least-used control — don't survive their structural flaw: the grip exists only on desktop track rows, so category would vanish on mobile, in the mixer, and in the picker, fragmenting the one system the label keeps whole. And color on an interactive affordance either promotes the wrong control (chip-styled O8 reads as press-me) or under-delivers hue (glyph-weight O7).
