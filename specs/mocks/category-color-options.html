Category Color: eight options, one principle

The strip's jobs are scanning (find the drums without reading), sectioning (same-hue neighbors read as a block), and anchoring (row identity survives horizontal scroll) — all classification, never state. Every option below is drawn on the same three rows, including a soloed row (purple outline) and a muted row (yellow M, dimmed) — because the real test is whether classification stays legible and quiet next to state.

Adopted: the name tick (O6 · L5)

Edges signal state. Labels signal class. Proximity binds color to identity.

The label placement stands — classification lives with the name — but the winning execution is the tick: a solid, text-height bar flush-left inside the name slot. It is the original strip's one virtue (solid color carries hue) with both of its sins corrected: bound to the name by Proximity instead of squatting on the row's state edge, and text-height instead of row-height. No box, no border, no button vocabulary — the name's pixels are untouched.

  • Spec: a 3px bar at full category saturation, height = the name's text box (top/bottom inset 2px), radius 2px, 6–7px clear of the text, flush-left in the existing name slot. Text stays --color-text; the tick dims with the row when muted; the row's left border is removed entirely. Name keeps its click-preview / rename behaviors — during rename, the tick stays beside the input.
  • Consistency (Repetition): the same label treatment carries category in the MixerPanel channel headers and the SamplePicker rows — one rule everywhere color classifies.
  • Hue as solid area: 3×16px of 100% saturation reads its hue instantly — more certain than any tint or hairline, at a fraction of the ink.
  • Vocabulary cost: zero. No new affordance, no new column — a pseudo-element on the existing name slot. Where a bigger color surface is wanted (e.g., the SamplePicker's category headers), the L2 fill-only label is the sanctioned bolder sibling.
  • If sectioning ever needs reinforcement (many same-category adjacent tracks), the O4 wash at ≤6% can be layered later as a group treatment — a separate decision, gated like everything else.
  • On the grip variants (O7/O8): their real merits — zero template cost, a clean name, double-duty for the least-used control — don't survive their structural flaw: the grip exists only on desktop track rows, so category would vanish on mobile, in the mixer, and in the picker, fragmenting the one system the label keeps whole. And color on an interactive affordance either promotes the wrong control (chip-styled O8 reads as press-me) or under-delivers hue (glyph-weight O7).
