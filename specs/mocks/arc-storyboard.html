Reference · the parameter lock editor, as it exists today

ParameterLockEditor.tsx · TrackRow.css :807

Open it by ⇧-clicking (or long-pressing) an active step. It appends a full-width strip below the track row — it does not float — and dismisses on click-outside. This is already inline expansion, already the house pattern, and already the thing the specs call "disclose."

End of Arc 3 · The First Sixty Seconds

This arc changes the screen a stranger meets. Sound is unlocked before load finishes, so the first tap is never silent; the empty session offers a real next action; and a landing example arrives already playing, one tap from Remix.

The through-line: Arc 1 takes one good pattern that already exists — the inline strip below the row — and makes it the app's only disclose mechanism, while collapsing 43 affordances to ~28. Arc 2 makes the thing trustworthy, Arc 3 makes the first minute survivable, and Arc 4 adds the only new musical capability in the plan, built entirely from parts visible in the Arc 1 frame.
